## 1. Magic UI

| Параметр | Значение |
|----------|----------|
| **Сайт** | [magicui.design](https://magicui.design/) |
| **GitHub** | [github.com/magicuidesign/magicui](https://github.com/magicuidesign/magicui) |
| **Звёзды** | 19,000+ |
| **Стек** | React, TypeScript, Tailwind CSS, Framer Motion |

**Описание:** UI-библиотека для дизайн-инженеров с фокусом на анимированные компоненты для лендингов. Признана 2-й по популярности UI-библиотекой 2024 года.

**Уникальные фичи:**
- 150+ бесплатных анимированных компонентов
- Анимированные фоны, текстовые эффекты, интерактивные карточки
- Готовые шаблоны лендингов
- Идеальный компаньон для shadcn/ui
- Pro-версия с 250+ блоками

**MCP-сервер:** Работает через официальный shadcn MCP (registry: @magicui)
