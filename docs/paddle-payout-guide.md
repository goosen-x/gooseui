## Обзор

### Как работают выплаты Paddle

Paddle — это Merchant of Record (MoR), который:
- Принимает платежи от клиентов по всему миру
- Обрабатывает налоги (VAT, Sales Tax)
- Выплачивает продавцам их долю (минус комиссия 5% + $0.50)

### График выплат

| Дата | Событие |
|------|---------|
| 1-е число месяца | Paddle формирует выплату |
| 15-е число месяца | Отправка платежа |
| +3-5 рабочих дней | Деньги на счёте |

### Минимальный порог

- **Минимум:** $100
- **Максимум:** $10,000
- Настраивается в Paddle Dashboard → Settings → Payouts

## Вариант 1: Payoneer

### Описание

Payoneer — международная платёжная система, предоставляющая виртуальные банковские счета в USD, EUR, GBP. Paddle отправляет деньги на ваш Payoneer-счёт как на обычный банк.

### Как настроить

1. Зарегистрироваться на [payoneer.com](https://www.payoneer.com)
2. Пройти верификацию (паспорт + подтверждение адреса)
3. Получить реквизиты USD Receiving Account
4. В Paddle Dashboard → Payouts → добавить банковские реквизиты Payoneer

### Реквизиты для Paddle

```
Bank Name: First Century Bank (или другой партнёр Payoneer)
Account Number: [ваш номер счёта]
Routing Number (ABA): [номер из Payoneer]
Account Type: Checking
```

### Комиссии

| Операция | Комиссия |
|----------|----------|
| Получение от Paddle | Бесплатно |
| Хранение на счёте | Бесплатно |
| Вывод на банк (USD→USD) | $1.50 |
| Вывод с конвертацией | 2% от суммы |
| Карта Payoneer | Бесплатно (выпуск ~$30) |

### Плюсы и минусы

**Плюсы:**
- Регистрация онлайн, без поездок
- Работает в большинстве стран
- Можно заказать физическую карту
- Принимает от многих платформ (не только Paddle)

**Минусы:**
- Комиссия 2% при конвертации
- Ограничения для некоторых стран (РФ — только вывод на зарубежные счета)
- Верификация может занять 3-7 дней

### Доступность по странам

| Страна | Статус |
|--------|--------|
| Израиль | ✅ Полный доступ |
| Киргизия | ✅ Полный доступ |
| Казахстан | ✅ Полный доступ |
| Грузия | ✅ Полный доступ |
| Россия | ⚠️ Ограничен (вывод только на зарубежные счета) |
| Беларусь | ❌ Не поддерживается |

## Вариант 2: Wise (TransferWise)

### Описание

Wise предоставляет мультивалютный счёт с локальными реквизитами в 10+ валютах. Низкие комиссии на конвертацию.

### Как настроить

1. Зарегистрироваться на [wise.com](https://wise.com)
2. Пройти верификацию
3. Открыть USD balance и получить реквизиты
4. В Paddle указать реквизиты Wise как банковский счёт

### Реквизиты для Paddle

```
Bank Name: Community Federal Savings Bank
Account Number: [ваш номер]
Routing Number: [ABA номер]
Account Type: Checking
SWIFT: CMFGUS33
```

### Комиссии

| Операция | Комиссия |
|----------|----------|
| Получение USD | Бесплатно |
| Конвертация USD→EUR | ~0.5% |
| Конвертация USD→ILS | ~0.5% |
| Вывод на банк | $0-3 (зависит от страны) |
| Карта Wise | Бесплатно |

### Плюсы и минусы

**Плюсы:**
- Самые низкие комиссии на конвертацию
- Реальный курс без наценки
- Карта работает везде
- Удобное приложение

**Минусы:**
- Не работает в РФ
- Лимиты на получение для некоторых стран
- Могут запросить подтверждение источника дохода

### Доступность по странам

| Страна | Статус |
|--------|--------|
| Израиль | ✅ Полный доступ |
| Грузия | ✅ Полный доступ |
| Казахстан | ⚠️ Ограниченный |
| Киргизия | ⚠️ Ограниченный |
| Россия | ❌ Не работает |
| Беларусь | ❌ Не работает |

## Вариант 3: Банк в Киргизии

### Описание

Открытие банковского счёта в Киргизии как физическое лицо. Страна не под санкциями, банки работают с SWIFT.

### Как открыть счёт

**Требования:**
- Личное присутствие в Киргизии
- Загранпаспорт
- Временная регистрация (делается за 1 день)
- Местная SIM-карта (опционально)

**Процесс:**
1. Прилететь в Бишкек
2. Сделать временную регистрацию
3. Посетить банк с документами
4. Счёт открывается за 1-3 дня

### Рекомендуемые банки

| Банк | USD счёт | Карта | Комиссия SWIFT |
|------|----------|-------|----------------|
| **Optima Bank** | ✅ | Visa | $15-25 |
| **KICB** | ✅ | Visa/MC | $20-30 |
| **Demir Bank** | ✅ | Visa | $15-20 |
| **Бакай Банк** | ✅ | Elcard | $15-25 |

### Настройка в Paddle

```
Bank Name: [Название банка]
SWIFT/BIC: [SWIFT код банка]
Account Number / IBAN: [Номер счёта]
Currency: USD
```

### Комиссии

| Операция | Комиссия |
|----------|----------|
| Paddle SWIFT fee | $15 |
| Банк входящий SWIFT | $15-30 |
| Обслуживание счёта | $0-5/мес |
| Снятие наличных USD | 1-2% |
| Конвертация USD→KGS | 1-2% |

### Плюсы и минусы

**Плюсы:**
- Полноценный банковский счёт
- Работает SWIFT без ограничений
- Можно получить карту Visa/Mastercard
- Нет санкций

**Минусы:**
- Нужен личный визит
- Комиссии выше чем Payoneer/Wise
- Обслуживание счёта (небольшое)

## Вариант 4: Банк в Казахстане

### Описание

Казахстан — ещё одна популярная юрисдикция для открытия счёта. Развитая банковская система, удобные приложения.

### Как открыть счёт

**Требования:**
- Личное присутствие
- Загранпаспорт
- ИИН (индивидуальный идентификационный номер) — делается за 1 день

**Процесс:**
1. Получить ИИН в ЦОНе (центр обслуживания населения)
2. Открыть счёт в банке
3. Получить карту

### Рекомендуемые банки

| Банк | Особенности |
|------|-------------|
| **Kaspi Bank** | Лучшее приложение, но сложно для нерезидентов |
| **Halyk Bank** | Проще открыть нерезиденту |
| **Forte Bank** | USD счета, SWIFT |
| **Freedom Finance** | Мультивалютный, инвестиции |

### Комиссии

| Операция | Комиссия |
|----------|----------|
| Paddle SWIFT fee | $15 |
| Банк входящий SWIFT | $20-40 |
| Обслуживание | $0-10/мес |
| Карта | Бесплатно |

### Плюсы и минусы

**Плюсы:**
- Развитая банковская инфраструктура
- Kaspi — одно из лучших банковских приложений в мире
- Можно открыть брокерский счёт
- Близко к РФ

**Минусы:**
- Kaspi сложно открыть нерезиденту
- ИИН нужно получать лично
- SWIFT комиссии высокие

## Вариант 5: Банк в Грузии

### Описание

Грузия — популярное направление для релокантов. Простое открытие счёта, работающий SWIFT.

### Как открыть счёт

**Требования:**
- Загранпаспорт
- Личное присутствие
- Грузинский номер телефона

**Процесс:**
1. Прилететь в Тбилиси/Батуми
2. Посетить банк
3. Счёт открывается за 15-30 минут

### Рекомендуемые банки

| Банк | USD счёт | Карта | Примечание |
|------|----------|-------|------------|
| **Bank of Georgia** | ✅ | Visa/MC | Самый крупный |
| **TBC Bank** | ✅ | Visa/MC | Хорошее приложение |
| **Liberty Bank** | ✅ | Visa | Проще открыть |

### Комиссии

| Операция | Комиссия |
|----------|----------|
| Paddle SWIFT fee | $15 |
| Банк входящий SWIFT | $10-20 |
| Обслуживание | $0-3/мес |
| Карта | Бесплатно |

### Плюсы и минусы

**Плюсы:**
- Быстрое открытие (30 минут)
- Низкие комиссии
- Английский язык в банках
- Работает Wise для вывода

**Минусы:**
- Нужен личный визит

## Налоговые аспекты

### Важно понимать

Paddle выступает как Merchant of Record — это значит:
- Paddle продаёт ваш продукт от своего имени
- Paddle платит налоги (VAT) за вас
- Вы получаете выплату как **роялти** или **комиссионные**

### Налоги по странам

| Страна | Налог на доход физлица | Примечание |
|--------|------------------------|------------|
| Израиль | 10-50% (прогрессивный) | Нужно декларировать |
| Киргизия | 10% | Можно оформить патент |
| Казахстан | 10% | Или ИП на упрощёнке 3% |
| Грузия | 20% | Или статус "малый бизнес" 1% |
| Россия | 13-15% | НДФЛ |

### Рекомендация

Для легальной работы и минимизации налогов рекомендуется:
1. Консультация с налоговым специалистом в вашей стране
2. Рассмотреть оформление ИП/самозанятости
3. Вести учёт всех поступлений

## Рекомендации

### Для резидентов Израиля

```
Лучший вариант: Wise или Payoneer
├── Открытие онлайн
├── Низкие комиссии
├── Карта для расходов
└── Вывод на израильский банк
```

### Для резидентов СНГ (кроме РФ/РБ)

```
Лучший вариант: Payoneer
├── Работает везде
├── Открытие онлайн
└── Вывод на местный банк
```

### Для резидентов РФ

```
Лучший вариант: Банк в Киргизии/Казахстане/Грузии
├── Личный визит для открытия
├── SWIFT работает
├── Можно снять наличные или перевести
└── Альтернатива: Payoneer → зарубежный счёт
```

### Общая рекомендация

1. **Начать с Payoneer** — самый простой старт
2. **Добавить Wise** — для низких комиссий конвертации
3. **Открыть зарубежный счёт** — когда объёмы вырастут
