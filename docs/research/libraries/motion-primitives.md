# Motion Primitives

> Источник: https://www.motion-primitives.com/
> Дата исследования: 2025-12-28
> Статус библиотеки: Beta, Open Source

## Обзор

Motion Primitives — это UI-библиотека анимационных компонентов для React/Next.js, построенная на базе Motion (Framer Motion) и Tailwind CSS. Библиотека предоставляет готовые к использованию анимированные компоненты с возможностью копирования исходного кода напрямую в проект.

**Ключевые характеристики:**

- 40+ анимационных компонентов
- Построена на Motion (Framer Motion) + Tailwind CSS
- Open Source (MIT License)
- Подход copy-paste (как у shadcn/ui)
- CLI для установки компонентов
- TypeScript поддержка

## Ценностное предложение

**Основной посыл:** "Beautifully designed motion components. Easy copy-paste. Customizable. Open Source. Built for engineers and designers."

**Целевая аудитория:** React/Next.js разработчики, которым нужны готовые анимационные решения без глубокого погружения в Framer Motion.

**Преимущества:**

1. **Экономия времени** — не нужно писать анимации с нуля
2. **Консистентность** — единый стиль анимаций
3. **Гибкость** — полный контроль над кодом после копирования
4. **Качество** — продуманные spring-анимации и easing функции
5. **Интеграция** — нативная поддержка Tailwind CSS

## Уникальные особенности

### 1. Text Scramble — криптографический эффект

```tsx
<TextScramble speed={0.01} characterSet="!@#$%^&*">
  Secret Message
</TextScramble>
```

Символы рандомно меняются перед финальным отображением. Создает "хакерский" эффект декодирования.

### 2. Border Trail — бегущая граница

```tsx
<BorderTrail size={60} transition={{ duration: 2, repeat: Infinity }} />
```

Анимированный элемент, движущийся вдоль границы контейнера. Использует CSS offset-path.

### 3. Morphing Dialog — layout-анимация

Диалог "вырастает" из триггера используя shared layout ID. Элементы плавно трансформируются от маленького к полноразмерному.

### 4. Magnetic — магнитное притяжение

```tsx
<Magnetic intensity={0.6} range={100}>
  <button>Hover me</button>
</Magnetic>
```

Элемент следует за курсором в заданном радиусе.

### 5. Dock — macOS магнификация

```tsx
<Dock magnification={80} distance={150}>
  <DockItem>
    <DockIcon>
      <HomeIcon />
    </DockIcon>
    <DockLabel>Home</DockLabel>
  </DockItem>
</Dock>
```

Точная копия поведения macOS dock с увеличением иконок.

### 6. Progressive Blur — градиентное размытие

```tsx
<ProgressiveBlur direction="bottom" blurLayers={8} blurIntensity={0.25} />
```

Многослойное размытие с градиентной маской. Идеально для fade-эффектов на изображениях.

## Технические детали

### Зависимости

```bash
npm install motion lucide-react
npm install clsx tailwind-merge
```

### Утилита cn()

```ts
// lib/utils.ts
import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

### Установка компонента

```bash
npx motion-primitives@latest add text-effect
```

### Структура компонента

- Каждый компонент полностью автономен
- Использует Motion для анимаций
- Стилизация через Tailwind CSS классы
- Типизация TypeScript
- Поддержка spring-анимаций и easing

### Пример API компонента (Text Effect)

```tsx
interface TextEffectProps {
  children: string
  per?: "word" | "char" | "line"
  preset?: "blur" | "fade" | "scale" | "slide" | "fade-in-blur"
  delay?: number
  speedReveal?: number
  speedSegment?: number
  trigger?: boolean
  variants?: MotionVariants
  onAnimationStart?: () => void
  onAnimationComplete?: () => void
}
```

### Рекомендации по интеграции

1. **Создать обертки** — адаптировать компоненты под дизайн-систему GooseLabs
2. **Унифицировать spring-настройки** — единые значения bounce, stiffness, damping
3. **Accessibility** — добавить `prefers-reduced-motion` поддержку
4. **Performance** — использовать `will-change` и GPU-ускорение осознанно
5. **Тестирование** — проверить на мобильных устройствах

### Потенциальные ограничения

- Зависимость от Motion (Framer Motion) — ~15KB gzipped
- Некоторые эффекты могут влиять на производительность при большом количестве
- Нет SSR-специфичных оптимизаций из коробки
- Beta статус — возможны breaking changes
