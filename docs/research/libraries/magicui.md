# MagicUI

## Обзор

MagicUI - это open-source библиотека UI компонентов для "Design Engineers", предлагающая коллекцию из 150+ анимированных компонентов и эффектов для React. Библиотека позиционируется как "perfect companion for shadcn/ui" и позволяет копировать компоненты напрямую в проект.

**GitHub**: https://github.com/magicuidesign/magicui
- 19.8k звезд
- 899 форков
- 129 контрибьюторов
- MIT лицензия

**Сайт**: https://magicui.design/

## Ценностное предложение

1. **Для Design Engineers** - целевая аудитория: разработчики с дизайнерским вкусом
2. **Copy & Paste подход** - компоненты копируются в проект, без npm-зависимости
3. **Анимации из коробки** - все компоненты анимированы с помощью Framer Motion
4. **Совместимость с shadcn/ui** - используется тот же CLI и структура
5. **Бесплатно и Open Source** - базовая библиотека полностью бесплатна

## Уникальные особенности

### 1. Фокус на Landing Pages
Все компоненты оптимизированы для создания впечатляющих лендингов стартапов и SaaS продуктов.

### 2. Анимации на Framer Motion
Каждый компонент имеет продуманные анимации. Типы анимаций в TextAnimate:
- `blurInUp` - размытие по символам
- `blurIn` - размытие текста
- `slideUp` - появление снизу по словам
- `scaleUp` - увеличение текста
- `fadeIn` - появление по строкам
- `slideLeft` - появление слева по символам

### 3. Интеграционные компоненты
- **Animated Beam** - показывает связи между элементами (для страниц интеграций)
- **Globe** - интерактивный 3D глобус для показа глобального присутствия
- **Icon Cloud** - 3D облако технологий/интеграций

### 4. MCP Server
Официальный MCP сервер для AI IDE:
- Прямой доступ к компонентам из Cursor, Claude
- Генерация кода с минимальными ошибками
- https://github.com/magicuidesign/mcp

### 5. Градиентные эффекты
- Border Beam с кастомными цветами через className
- Shine Border с массивом цветов `["#A07CFE", "#FE8FB5", "#FFBE7B"]`
- Magic Card с поддержкой темной и светлой темы


## Скриншоты/Примеры

### Визуальные элементы

**Border Beam**
Анимированный луч света, путешествующий по границе контейнера. Параметры:
- `duration` - длительность анимации
- `size` - размер луча
- `reverse` - направление
- Кастомные цвета: `from-transparent via-green-500 to-transparent`

**Magic Card**
Карточка с градиентным эффектом, следующим за курсором:
- `gradientColor="#262626"` для темной темы
- `gradientColor="#D9D9D955"` для светлой темы

**Globe**
3D глобус на базе библиотеки Cobe:
- Интерактивное вращение
- Маркеры городов
- Дуги между точками

**Orbiting Circles**
Иконки, вращающиеся вокруг центрального элемента:
- Разные радиусы орбит
- Разные скорости вращения
- Двунаправленное движение

**Animated Beam**
SVG-лучи между элементами:
- Показывает flow данных
- Анимированное свечение
- Кастомные paths
