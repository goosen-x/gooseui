# Kibo UI

## Обзор

**Kibo UI** — это кастомный реестр (registry) компонентов, построенный поверх shadcn/ui. Библиотека предоставляет готовые, полностью компонуемые, доступные и расширяемые компоненты для React-приложений.

- **Сайт**: https://www.kibo-ui.com/
- **GitHub**: https://github.com/haydenbleasel/kibo
- **Лицензия**: MIT
- **Звезды на GitHub**: 3,500+
- **Основной язык**: TypeScript (97%)

## Технологический стек

- **React** 18+
- **TypeScript**
- **Tailwind CSS**
- **Radix UI** (примитивы доступности)
- **Lucide** (иконки)
- **shadcn/ui** (базовая система)

## Ключевые особенности

1. **Построен на shadcn/ui** — расширяет экосистему shadcn, добавляя более сложные компоненты
2. **Полная компонуемость** — компоненты можно кастомизировать и расширять под свои нужды
3. **Копируемый код** — код компонентов копируется в проект, давая полный контроль
4. **Доступность** — построен на Radix UI примитивах
5. **MCP Server поддержка** — интеграция с Model Context Protocol для AI-разработки
6. **Open Source** — полностью бесплатный и открытый

## Установка

### Требования

- Node.js 18+
- React 18+
- shadcn/ui уже настроен в проекте
- Tailwind CSS с CSS Variables режимом

### Способы установки компонентов

**Через Kibo UI CLI:**

```bash
npx kibo-ui add gantt
```

**Через shadcn CLI:**

```bash
npx shadcn@latest add gantt
```

Компоненты устанавливаются в директорию `@/components/kibo-ui/`.

## Детальный разбор ключевых компонентов

### Gantt Chart

Мощный инструмент для визуализации проектных расписаний.

**Возможности:**

- Изменяемые и перетаскиваемые элементы таймлайна
- Маркеры для важных дат
- Маркер "Сегодня"
- Группировка задач
- Несколько элементов в строке (бронирование отелей и т.п.)
- Режим только для чтения

**Зависимости:** dndkit, date-fns, lodash, lucide, jotai

```bash
npx kibo-ui add gantt
```

### Kanban Board

Визуальный инструмент управления задачами с колонками статусов.

**Возможности:**

- Drag-and-drop между колонками
- Кастомизируемое содержимое карточек
- Интеграция с проектным тулкитом

**Зависимости:** dndkit

```bash
npx kibo-ui add kanban
```

### Editor (Rich Text)

Полнофункциональный текстовый редактор.

**Возможности:**

- Форматирование: bold, italic, underline, strikethrough, code
- Цвета текста и фона
- Таблицы с управлением ячейками
- Блоки кода с подсветкой синтаксиса
- Заголовки H1-H3, списки, чеклисты
- Slash-команды для быстрого форматирования
- Подсчет символов и слов

**Зависимости:** TipTap, Lucide, Lowlight, Tippy.js, Fuse.js

```bash
npx kibo-ui add editor
```

### Code Block

Компонент для отображения кода.

**Возможности:**

- Подсветка синтаксиса (Shiki)
- Номера строк
- Копирование в буфер
- Имена файлов
- Подсветка строк и слов
- Diff-режим
- Режим фокуса
- Поддержка тем
- RSC (React Server Component) версия

```bash
npx kibo-ui add code-block
```

### Dropzone

Drag-and-drop загрузка файлов.

**Возможности:**

- Кастомизируемые empty-состояния
- Валидация типа, размера, количества файлов
- Человекочитаемые имена и размеры
- Обработка ошибок
- Превью изображений
- Замена файлов через drag-and-drop

**Зависимости:** react-dropzone, lucide

```bash
npx kibo-ui add dropzone
```

### Color Picker

Выбор цвета в стиле Figma.

**Возможности:**

## Сравнение с shadcn/ui

| Аспект                  | shadcn/ui                               | Kibo UI                                    |
| ----------------------- | --------------------------------------- | ------------------------------------------ |
| Фокус                   | Базовые примитивы (Button, Card, Input) | Сложные компоненты (Gantt, Kanban, Editor) |
| Основа                  | Radix UI                                | shadcn/ui + Radix UI                       |
| Уровень абстракции      | Низкий                                  | Высокий                                    |
| Готовность к продакшену | Требует доработки                       | Готовые решения                            |
| Кастомизация            | Полная                                  | Полная                                     |

## Когда использовать Kibo UI

**Рекомендуется для:**

- Быстрого прототипирования продуктов
- Стартапов, которым нужно быстро выпускать фичи
- Проектов, требующих Gantt/Kanban/Editor "из коробки"
- Команд, уже использующих shadcn/ui

**Может не подойти для:**

- Проектов без shadcn/ui
- Случаев, когда нужен полный контроль над низкоуровневыми примитивами
- Минималистичных проектов без сложных компонентов
