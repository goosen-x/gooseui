## Обзор

KokonutUI — открытая коллекция из 100+ современных UI-компонентов, построенных на Tailwind CSS, shadcn/ui и Motion (Framer Motion). Библиотека создана Dorian Baffier (Aris Studio) и получила поддержку Vercel в рамках OSS 2025 Program.

## Ценностное предложение

### Основные преимущества
1. **Современные анимации** — все компоненты используют Motion (Framer Motion) для плавных переходов
2. **Glass-эффекты** — Apple-inspired glassmorphism дизайн (Liquid Glass)
3. **Интеграция с V0** — возможность открыть любой компонент в интерактивном редакторе Vercel V0
4. **shadcn CLI** — одна из первых библиотек с полной поддержкой shadcn registry
5. **AI-компоненты** — специализированные компоненты для AI-интерфейсов

### Технологический стек
- React / Next.js
- TypeScript
- Tailwind CSS v4
- Motion (Framer Motion)
- shadcn/ui (базовые примитивы)

## Структура документации

### Установка
```bash
# Инициализация конфигурации
bunx --bun shadcn@latest init
# или
npx shadcn@latest init
# или
pnpm dlx shadcn@latest init

# Добавление registry в components.json
{
    "registries": {
        "@kokonutui": "https://kokonutui.com/r/{name}.json"
    }
}

# Установка компонента
bunx --bun shadcn@latest add @kokonutui/liquid-glass-card
```

## Уникальные особенности

### 1. Apple-inspired Glassmorphism
Liquid Glass — компонент создает эффект стеклянной поверхности, вдохновленный дизайном Apple. Использует продвинутые CSS-фильтры и blur-эффекты.

### 2. Интеграция с V0
Каждый компонент можно открыть в Vercel V0 для интерактивного редактирования и кастомизации. KokonutUI была одной из первых библиотек, добавивших эту функцию.

### 3. Ранняя поддержка shadcn CLI
Одна из первых сторонних библиотек, интегрировавшихся с shadcn registry (январь 2024), еще когда не было официальной документации.

### 4. AI-компоненты
Специализированная категория компонентов для AI-интерфейсов:
- Инпуты с AI-стилем
- Индикаторы загрузки AI-ответов
- Голосовой интерфейс
- Селекторы моделей

### 5. Morphing-анимации
Morphic Navbar демонстрирует плавное преобразование формы фона при переключении активных элементов навигации.

### 6. Интерактивные эффекты мыши
Mouse Effect Card — карточка с анимированным dot-паттерном, реагирующим на движение мыши.

### 7. Bento Grid с интерактивностью
Сетка карточек включает:
- Голосовой ассистент
- Партнерские логотипы
- AI-агенты и автоматизация
- Enterprise технологии

## Технические детали

### Зависимости
- Tailwind CSS v4 (обязательно)
- Motion (Framer Motion) для анимаций
- lucide-icons для иконок
- shadcn/ui компоненты (устанавливаются автоматически)

### Структура репозитория
```
kokonutui/
├── app/              # Next.js приложение (документация)
├── components/       # Исходный код компонентов
├── registry/         # Registry для shadcn CLI
├── content/docs/     # MDX документация
├── hooks/            # React hooks
├── lib/              # Утилиты
├── public/           # Статика
├── scripts/          # Скрипты сборки
└── config/           # Конфигурация
```

### CLI интеграция
```bash
# Добавление одного компонента
bunx --bun shadcn@latest add @kokonutui/morphic-navbar

# Компоненты устанавливаются в:
# - components/ui/ для shadcn-совместимых
# - components/kokonut/ для специфичных
```
