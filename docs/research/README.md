# Исследование библиотек компонентов

Дата исследования: 28 декабря 2025

## Цель исследования

Изучить лучшие практики и уникальные решения из 20 популярных библиотек компонентов, совместимых с shadcn/ui, для создания высококачественной библиотеки GooseLabs UI.

## Исследуемые библиотеки

### Анимации и эффекты
1. [MagicUI](./libraries/magicui.md) - Анимированные компоненты для landing pages
2. [Aceternity UI](./libraries/aceternity-ui.md) - Современные анимации и эффекты
3. [Motion Primitives](./libraries/motion-primitives.md) - Примитивы для анимаций
4. [Animate UI](./libraries/animate-ui.md) - Анимационные компоненты
5. [SmoothUI](./libraries/smoothui.md) - Плавные анимации

### AI и чат-интерфейсы
6. [Assistant UI](./libraries/assistant-ui.md) - Компоненты для AI-чатов

## Источник данных

Все библиотеки взяты из официального [Registry Directory](https://ui.shadcn.com/docs/directory) shadcn/ui.

## Структура документации каждой библиотеки

- **Обзор** - краткое описание
- **Ценностное предложение** - что предлагает библиотека
- **Структура документации** - как организована документация
- **Компоненты** - список доступных компонентов
- **Уникальные особенности** - что выделяет библиотеку
- **Технические детали** - стек, зависимости
- **Что можно внедрить** - идеи для GooseLabs UI
