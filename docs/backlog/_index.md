# GooseUI Backlog

## Структура

| Папка | Описание |
|-------|----------|
| `ideas/` | Сырые идеи, требуют проработки |
| `todo/` | Готовы к реализации |
| `in-progress/` | В работе |
| `done/` | Завершённые |

## Статусы задач

- `[ ]` — не начато
- `[/]` — в процессе
- `[x]` — завершено

## Приоритеты

- `#p1` — критично, делать первым
- `#p2` — важно
- `#p3` — было бы неплохо

## Теги

- `#component` — новый компонент
- `#effect` — визуальный эффект
- `#feature` — функциональность
- `#improvement` — улучшение существующего
- `#docs` — документация

## Быстрые ссылки

## Как добавить идею

Попроси Claude:
```
"Добавь идею: [описание]"
```

Или создай файл вручную в `ideas/` по шаблону.
