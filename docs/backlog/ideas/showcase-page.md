# Showcase Page

#p2 #marketing #monetization

## Описание

Страница с примерами реальных проектов, использующих GooseUI. Может быть частью монетизации — показывать бесплатные примеры и upsell на платные шаблоны.

## Варианты реализации

### Вариант 1: Отдельная страница Showcase
- `/showcase` — галерея проектов
- Скриншоты/превью сайтов
- Ссылки на live-версии
- Фильтрация по категориям (SaaS, E-commerce, Portfolio, etc.)

### Вариант 2: Объединить с Templates (платные)
- Showcase = бесплатные примеры для вдохновения
- Templates = готовые шаблоны за деньги
- Showcase как воронка в Templates

### Вариант 3: Community Showcase
- Пользователи сабмитят свои проекты
- Модерация перед публикацией
- Бейджи "Built with GooseUI"

## Структура страницы

```
/showcase
├── Hero: "Built with GooseUI"
├── Featured projects (3-5 лучших)
├── Grid с проектами
│   ├── Screenshot
│   ├── Название
│   ├── Категория
│   └── [View Site] [View Template?]
└── CTA: "Want your project featured?"
```

## Связь с Templates

- Showcase показывает ЧТО можно построить
- Templates продаёт КАК это построить
- Каждый showcase может ссылаться на template (если есть)
