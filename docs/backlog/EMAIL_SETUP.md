# Настройка email info@gooseui.pro

## Задача
Настроить почту для домена gooseui.pro

## Варианты

### 1. Cloudflare Email Routing (бесплатно)
- Если домен на Cloudflare
- Dashboard → Email → Email Routing
- Пересылка на личную почту

### 2. Zoho Mail (бесплатно до 5 юзеров)
- https://zoho.com/mail
- Полноценный почтовый клиент

### 3. Google Workspace ($6/мес)
- Gmail для домена
- Интеграция с Google сервисами

### 4. Fastmail ($5/мес)
- Privacy-friendly
- Хорошая репутация

## Рекомендация
Cloudflare Email Routing — бесплатно, быстро настраивается.
