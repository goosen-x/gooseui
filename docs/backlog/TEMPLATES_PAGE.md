# Templates Page (Premium)

## Задача
Создать страницу с платными шаблонами для монетизации проекта.

## Референсы
- https://kokonutui.pro/templates#sonae
- https://pro.magicui.design/

## Идеи для шаблонов
- SaaS Dashboard
- Landing Page
- Admin Panel
- E-commerce
- Portfolio
- Blog

## Модель монетизации
- Разовая покупка шаблона
- Или подписка на все шаблоны

## Технические требования
- Интеграция с платёжной системой (Stripe, Lemon Squeezy)
- Система лицензий
- Скачивание после оплаты
