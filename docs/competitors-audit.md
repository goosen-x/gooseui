9. **Kibo UI** — 3.2k ⭐ (продвинутые)
10. **Motion Primitives** — 3k+ ⭐ (анимации)

### Тренды рынка
- **Анимации** — самая популярная категория (Magic UI, Aceternity, Motion Primitives)
- **AI компоненты** — быстрорастущий сегмент (assistant-ui, Prompt Kit)
- **NeoBrutalism** — набирающий популярность стиль (RetroUI)
- **Glassmorphism** — Apple-inspired дизайн
- **Base UI** — альтернатива Radix (BaseCN, COSS)

### Технологический стек
- **Tailwind CSS** — практически везде
- **Framer Motion / Motion** — для анимаций
- **GSAP** — для сложных анимаций (PaceUI, UI Layouts)
- **React Aria** — для accessibility (Intent UI, Taki)
- **TypeScript** — стандарт

## 🎯 Рекомендации для Goos UI

1. **Дифференциация** — выбрать уникальную нишу или стиль
2. **Анимации** — обязательно включить (это тренд)
3. **AI компоненты** — растущий рынок
4. **Accessibility** — React Aria или Radix
5. **Documentation** — качественная документация критична
6. **CLI** — поддержка shadcn CLI для установки
