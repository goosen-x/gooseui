# GooseUI - Impact Description

> For Vercel Open Source Program application

## One-liner

Free, open-source UI components and effects for React/Next.js. Built on shadcn/ui with additional animations and polished components. Copy, paste, ship.

## What is GooseUI?

GooseUI is a modern component library that extends shadcn/ui with:
- Animated UI components (checkboxes, timers, clocks)
- Visual effects (border beam, gradients)
- Ready-to-use blocks and examples
- Full shadcn/ui registry compatibility

## Tech Stack

- **Framework**: Next.js 15, React 19
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Primitives**: Radix UI
- **Language**: TypeScript

## Why GooseUI?

1. **Free & Open Source** - MIT licensed, no paywalls
2. **Copy-paste friendly** - Works with shadcn CLI
3. **Production ready** - Used in real projects
4. **Modern stack** - Latest Next.js, React, Tailwind
