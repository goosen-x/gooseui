# Web3 Blocks & Components

## Референсы

### Creative Tim - Web3 Collection

**URL:** https://www.creative-tim.com/ui/blocks/web3-collection/web3-login

Коллекция готовых блоков для Web3 приложений:

| Блок | Описание |
|------|----------|
| Web3 Login | Формы входа с Wallet Connect |
| NFT Cards | Карточки NFT с метаданными |
| Token Dashboard | Дашборды для токенов |
| Wallet Connect | Кнопки подключения кошельков |

### Идеи для GooseUI Web3 компонентов

- [ ] **WalletConnectButton** — кнопка подключения кошелька (MetaMask, WalletConnect, Coinbase)
- [ ] **AddressDisplay** — отображение адреса с копированием и сокращением (0x1234...abcd)
- [ ] **NFTCard** — карточка NFT с изображением, названием, ценой
- [ ] **TokenBalance** — отображение баланса токена с иконкой
- [ ] **TransactionStatus** — статус транзакции (pending, confirmed, failed)
- [ ] **NetworkSwitcher** — переключатель сети (Ethereum, Polygon, etc.)
- [ ] **GasEstimate** — отображение стоимости газа

### Библиотеки для интеграции

**Компоненты:**

| Компонент | Описание |
|-----------|----------|
| **PriceCard** | Цена с графиком, изменением %, период |
| **StakingCard** | Стейкинг метрики с APR |
| **WalletStatCard** | Компактная карточка кошелька |
| **SparklineChart** | Мини-график (area chart) |
| **PercentBadge** | Бейдж с % изменением (зелёный/красный) |

**Особенности дизайна:**

- Чистый белый фон карточек
- Тонкая серая граница (`border-gray-200`)
- Зелёный для положительных изменений (`text-green-500`)
- Красный для отрицательных (`text-red-500`)
- Sparkline графики без осей (минимализм)
- Dropdown для выбора периода (Last 24H)
- Иконки кошельков с брендовыми цветами
