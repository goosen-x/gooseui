# Marketing Blocks & Components

## Референсы

### Creative Tim - Promo Banner Popup

**URL:** https://www.creative-tim.com

Промо-баннер для акций и распродаж:

#### Структура

```
┌─────────────────────────────────────────────┐ ✕
│  ❄️ ❄️                                      │
│  🏷️ Creative Tim                            │
│                                              │
│  Winter Campaign Edition                     │
│  ════════════════════════════════════════    │
│  START 2026 WITH A BANG!                     │
│                                              │
│  Starting from                               │
│  $229   ̶$̶1̶,̶4̶4̶4̶                              │ ← зачёркнутая цена
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │  [Screenshot 1] [Screenshot 2]         │  │
│  │  [Screenshot 3] [Screenshot 4]         │  │ ← grid продуктов
│  └────────────────────────────────────────┘  │
│                                              │
├──────────────────────────────────────────────┤
│ ◀ 3 DAYS LEFT | FIRST 100 | 3 DAYS LEFT | ▶ │ ← marquee лента
│ ◀ FIRST 100 | 3 DAYS LEFT | FIRST 100 |   ▶ │ ← вторая лента
└──────────────────────────────────────────────┘
```

#### Особенности дизайна

| Элемент | Описание |
|---------|----------|
| **Фон** | Тёмно-синий градиент с анимированными снежинками |
| **Логотип** | Белый, в левом верхнем углу |
| **Заголовок** | Крупный, белый, bold |
| **Цена** | Акционная зелёная/оранжевая + зачёркнутая серая |
| **Скриншоты** | Grid 2x2 с превью продуктов под углом |
| **Marquee** | Две бегущие строки с URGENCY текстом |
| **Кнопка закрытия** | ✕ в правом верхнем углу |

#### Цветовая схема

```css
--promo-bg: linear-gradient(135deg, #0f172a, #1e3a5f);
--promo-accent: #f97316; /* orange для цены */
--promo-text: #ffffff;
--promo-muted: #94a3b8;
--marquee-bg: #dc2626; /* red лента */
```

#### Психологические триггеры

- **Urgency:** "3 DAYS LEFT", "FIRST 100"
- **Scarcity:** Ограниченное количество
- **Anchoring:** Зачёркнутая высокая цена ($1,444 → $229)
- **Social proof:** Превью реальных продуктов
