## ✨ Уникальные преимущества

GooseUI — единственная библиотека, которая специализируется на **современных CSS и Web API технологиях:**

1. **OKLch цветовая система** — точные переходы light/dark
2. **View Transitions API** — нативные морфинг-анимации
3. **CSS @property** — кастомные анимируемые свойства
4. **Container Queries** — responsive без media queries
5. **Математические формы** — Squircle (суперэллипс)
6. **Zero-dependency подход** — только CSS, минимум JS

**Никто из 65 библиотек не фокусируется на этих технологиях.**
